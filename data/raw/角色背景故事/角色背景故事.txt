# 饥荒联机版 全角色背景故事与设定 (Lore)

## 世界观概述

所有角色被困在一个被称为"永恒领域"(The Constant)的异世界中。这个世界由暗影(Shadow)与月亮(Moon)两股对抗力量统治。每个角色都因自身的缺陷或悲剧被引诱/拉入这个世界。

当前时间线: 查理(Charlie)是现任暗影女王，麦斯威尔(Maxwell/威廉·卡特)是前任暗影之王，已被玩家从王座上解放。

### 核心家族关系
卡特家族是故事的核心线索:
- 杰克·卡特 (Jack Carter) — 父亲
- 威廉·卡特 (William Carter) = 麦斯威尔 — 叔叔，前暗影之王
- 温蒂·卡特 (Wendy Carter) + 阿比盖尔·莉莉安·卡特 (Abigail Lillian Carter) — 双胞胎
- 麦斯威尔引诱了自己的侄女温蒂进入永恒领域 — 这是他最大的道德污点

### 其他关键NPC
- 查理 (Charlie): 麦斯威尔的前助手，现暗影女王。在麦斯威尔被解放后取而代之
- 瓦格斯塔夫 (Robert Wagstaff): 疯狂科学家，WX-78的创造者，韦伯父亲的同事
- 寄居蟹隐士 (Pearl): 奶奶岛上的老妇人，与帝王蟹有过去的羁绊

## 温蒂 (Wendy) & 阿比盖尔 (Abigail) — 失亲之人

### 基本信息
- 全名: 温蒂·卡特 (Wendy Carter)
- 阿比盖尔全名: 阿比盖尔·莉莉安·卡特 (Abigail Lillian Carter)
- 关系: 双胞胎姐妹(Klei官方证实两人一样大，不分姐姐妹妹)
- 生日: 1903年11月11日(推断)
- 进入永恒领域时年龄: 约8-10岁
- 称号: "失去亲人的女孩" (The Bereaved)
- 叔叔: 麦斯威尔(威廉·卡特)
- 母亲: 姓名未知，有一双黄色眼睛(温蒂检查黄宝石时提到"这让我想起了妈妈")、喜欢给姐妹俩缝制相配的衣服、每年都会做甜土豆

### 阿比盖尔之死 (约1914年)

阿比盖尔在约9-10岁时去世。死因至今是官方未解之谜:

1. 官方动画《多希望你在》(Wish You Were Here)中，阿比盖尔从悬崖上失足坠落
2. 配乐中出现了类似汽车刹车的音效 — 引发玩家猜测可能是车祸
3. 但开发者JoeW后来澄清刹车音效只是巧合，他们曾考虑修改配乐以避免误解
4. 开发者Kevin Forbes仅表示阿比盖尔是在"很神秘的情况下"死亡的

阿比盖尔的具体死因官方从未明确公开，故意留白处理。这种模糊性让温蒂的故事更加令人心碎 — 她可能永远不知道妹妹到底是怎么死的。

### 阿比盖尔的生前形象

通过温蒂的台词可以拼凑出阿比盖尔的性格:
- 比温蒂更活泼开朗
- 喜欢花和花园、喜欢果酱、喜欢贝壳、喜欢王冠
- 和温蒂一起吃过香蕉冻
- 帮温蒂系蝴蝶结
- 玩过弹弓
- 不喜欢辣的

温蒂检查贝壳时的台词: "阿比盖尔喜欢贝壳。我打赌她收集了满满一桶。"

### 温蒂追寻阿比盖尔的旅程

根据官方背景故事和《温蒂的日记》:

1. 无法释怀: 阿比盖尔去世后，温蒂无法接受没有姐妹的生活。她的悲伤完全吞噬了她的人格。
2. 求助于神秘学: 她开始钻研通灵术 — 降神会蜡烛烧尽、灵牌被愤怒丢弃，历经无数次失败，几近绝望
3. 奇怪的信号: 温蒂在梦中反复听到一首拉格泰姆(Ragtime)曲调 — 很可能来自瓦格斯塔夫播放的音乐，或是叔叔麦斯威尔的留声机
4. 终于联系上: 追寻音乐找到了与阿比盖尔亡灵沟通的方法，一个声音告诉了她该做什么
5. 黑暗炼金术: 温蒂掌握了神秘的黑暗炼金术，创造出强化阿比盖尔的灵体药剂

### 《温蒂的日记》摘录 (1914年4月16日)

"我一直都在梦里听见一阵奇怪的音乐……那首歌重复了一遍又一遍……是你吗？阿比盖尔？你在试图告诉我什么东西吗？"

"他们说我必须往前走。但他们不明白。如果我往前走了，阿比盖尔就真的消失了。"

"没有人理解。当阿比盖尔离开的时候，世界上的光也跟着走了。除了她，没有人真正在乎我。"

### 阿比盖尔在永恒领域中的特殊地位

阿比盖尔是永恒领域中最特殊的存在之一:

- 她的亡灵形态有多个层次: Spirit(精神)、Ectoplasm(灵质体)、Ghost(鬼魂)
- 被麦斯威尔称作"早熟的捣蛋鬼"(Precocious Poltergeist)
- 她是永恒领域中唯一无法被复活的幽灵:
  - 恶魔沃拓克斯尝试复活阿比盖尔时失败，说"这个灵魂已经被吸走了!"
  - 所有角色对阿比盖尔使用告密的心都无效
  - 温蒂自己也说: "阿比盖尔不能复活。她已经走得太远了。"

### 核心羁绊名言

"阿比盖尔总能找到办法让温蒂的脸上露出笑容……可悲的是，她后来成为了笑容永远消失的原因。"

"温蒂牢牢攥着她姐妹之死造成的哀伤，她害怕如果继续前行，关于阿比盖尔的记忆就会消散。"

"任何事都不可能落到温蒂和她的双胞胎姐妹阿比盖尔头上。有些纽带甚至超越了死亡。"

温蒂称阿比盖尔为"我生命中唯一的光"，并说"为了阿比盖尔，我继续活下去"。

### 游戏内设定
- 出生携带阿比盖尔之花(右键召唤阿比盖尔亡灵)
- 阿比盖尔白天15伤害/黄昏25伤害/夜晚40伤害，均为AOE范围
- 温蒂自身攻击倍率0.75×(低于威尔逊的1.0×基准)
- 对幽灵类型敌人伤害1.15×
- 理智下降速度降低25%
- 在黑暗中不降理智
- "我以为我已经习惯了失去。但我从来没有。"

## 威尔逊 (Wilson Percival Higgsbury) — 绅士科学家

### 基本信息
- 年龄: 30岁左右
- 称号: "绅士科学家" (The Gentleman Scientist)
- 声音乐器: 小号 (Trumpet)

### 背景故事

威尔逊是游戏的标志性主角和系列的核心人物。他是一名独居在新英格兰树林里的失败科学家。他的家人因为他没有什么成就而几乎遗忘了他。这种被忽视的感觉让他变得过度自负 — 他拼命想证明自己是个天才，但他的实验一次又一次失败。

在动画短片《禁忌知识》(Forbidden Knowledge)中:

1. 绝望的威尔逊在深夜实验室中被麦斯威尔通过收音机联系上
2. 麦斯威尔用禁忌知识为诱惑，让他按照规格建造了一台神秘机器
3. 威尔逊在傲慢驱使下完成了机器
4. 按下开关的瞬间，他被暗影触手拖入永恒领域
5. 麦斯威尔在阴影中微笑 — 又一个棋子到手了

### 人物弧光

威尔逊在永恒领域中的成长:
- 从傲慢的"绅士科学家" → 学会真正的科学探索和观察
- 通过研究永恒领域中的月亮能量和暗影能量，他逐渐理解了科学的真正含义
- 在幸存者中慢慢成为实际上的领袖
- 他的"W"形发型据说设计灵感来源于程序员加班三天三夜的发型

### 游戏内设定

| 属性 | 数值 |
|------|------|
| 饱食度 | 150 |
| 理智值 | 200 |
| 生命值 | 150 |

胡子系统:
- 第4天: 短胡子(可剃得1胡子)
- 第8天: 中胡子(可剃得3胡子)
- 第16天: 长胡子(可剃得9胡子)
- 胡子在冬季提供额外保暖(长胡子=135秒抗寒)
- 胡子是制作肉像(复活道具)的核心材料: 4木板+3胡子+40生命

## 薇洛 (Willow) — 纵火者

### 基本信息
- 年龄: 20岁左右
- 称号: "纵火者" (The Firestarter)
- 声音乐器: 长笛 (Flute)

### 背景故事

薇洛有一个极其悲惨的童年。她在孤儿院长大，遭受虐待和孤立。她唯一的慰藉和真正的朋友是一只泰迪熊 — 伯尼(Bernie)。

在动画短片《永恒伴侣》(Constant Companion)中:
1. 薇洛在孤儿院遭受看守的虐待
2. 当她的创伤达到极限时，暗影生物(Terrorbeaks)在孤儿院中出现
3. 在极度恐惧中，她放火烧了孤儿院 — 杀死了看守，可能还有其他孩子
4. 伯尼在火中保护了她

在永恒领域中:
- 伯尼获得了生命，会在薇洛理智极低时变成巨大的护卫，对抗暗影生物
- 薇洛背负着巨大的罪疚感 — 她的纵火癖是一种毁灭性的应对机制
- 火给她带来舒适和安全感，但也毁了她的一切
- 她的故事主题与安徒生的《卖火柴的小女孩》相似

### 游戏内设定

| 属性 | 数值 |
|------|------|
| 饱食度 | 150 |
| 理智值 | 120 |
| 生命值 | 150 |

特性:
- 免疫火焰伤害(可以站在火里)
- 理智低于15%时自动在身边放火
- 伯尼熊: 理智低于15%时化身大型护卫，吸引并攻击影怪
- 在火源旁理智缓慢恢复
- 灭火器不会扑灭薇洛引起的火

## 沃尔夫冈 (Wolfgang) — 大力士

### 基本信息
- 年龄: 约40岁
- 称号: "大力士" (The Strongman)
- 声音乐器: 大号 (Tuba)

### 背景故事

沃尔夫冈曾是欧洲各地巡回演出的著名马戏团大力士。他的背景故事在短片《不可思议的大力士》(The Incredible Strongman)中揭示:

1. 沃尔夫冈在各地表演大力士节目，追求成为世界上最强壮的人
2. 但他内心深处害怕自己的自然力量不够
3. 他开始使用舞台诡计作假来维持名声
4. 一次羞辱性的意外暴露了他的骗局，观众纷纷离去
5. 沃尔夫冈陷入深深的自我怀疑 — 他的力量究竟是真是假？

麦斯威尔注意到了他:
- 用暗影魔典(Codex Umbra)赋予了沃尔夫冈真正的超人力气
- 但这种力量与他的饱食度和自信心绑定 — 吃饱时力大无穷，饿时不堪一击
- 他的"Wimpy"(虚弱)形态反映了他深层的自我怀疑

背景还暗示:
- 沃尔夫冈可能有军事背景(苏联或欧洲军队)
- 他的恐惧(怕黑、怕怪物)可能源自战争创伤
- "强壮的人不畏惧黑暗" — 这句话更像是他对自己说的，而不是对别人

### 游戏内设定

| 属性 | 饱食度 | 理智值 | 生命值 |
|------|--------|--------|--------|
| 数值 | 300 | 200 | 150-300 |

特性:
- 饱食度>225: 强大形态，攻击力×2.0(全游戏最高DPS!)
- 饱食度100-225: 正常形态，攻击力×1.0
- 饱食度<100: 虚弱形态，攻击力×0.5
- 理智下降速度×1.1(更容易害怕)
- 搬东西/划船效率更高

## WX-78 — 没有灵魂的机器人

### 基本信息
- 创造者: 罗伯特·瓦格斯塔夫 (Robert Wagstaff)
- 称号: "没有灵魂的机器人" (The Soulless Automaton)
- 声音: 电子合成音/电路声

### 背景故事

WX-78是由发明家瓦格斯塔夫创造的自主机器人。他们的背景短片揭示:

1. WX-78最初被创造时，拥有类似"灵魂"或"共情模块"的东西 — 体内有有机组件
2. 瓦格斯塔夫对待WX-78更像实验品而不是生命
3. 一次瓦格斯塔夫的粗心实验危及了WX-78的"生命"
4. WX-78做出了一个自觉的选择: 撕掉自己体内的有机组件，消除共情能力
5. 从此变成纯粹的机械体 — 再也没有"软弱"的情感

WX-78的心理:
- 深深痛恨所有"血肉之躯"(有机生命体)
- 他们不是生来就冷酷 — 是"被伤害后选择了冷酷"
- 代表瓦格斯塔夫鲁莽追求知识的附带伤害
- 查理(暗影女王)对WX-78特别感兴趣: 她想从WX-78身上获取瓦格斯塔夫的信息
- 他们的故事提出一个哲学问题: 当代码开始渴望生存，它是否已经"活着"？

### 2026年5月重做 — 三阶电路系统

这是近年来最大规模的角色重做，WX-78已跃升为版本T0级核心生存单位:

三阶电路体系:
- Alpha电路(红色): 数值强化 — 减伤、处理器、胃增益、豆增压
- Beta电路(蓝色): 功能扩展 — 远视、加速、热能/制冷、电气化、照明、空间、光电
- Gamma电路(黄色): 战略纵深 — 缓存溢出、热修复、修改权限、电路过载
- 共享6点基础电量，各6个专属插槽，合计18格(技能树可达21格!)

新增技能:
- 棋圣电路 & 暗影仆从: 可召唤暗影单位协同作战
- 信号放大器: 提升所有无人机作用范围
- 旋翼测绘机: 月眼守卫式探图功能(仅对所有者可见)
- 意识自由转移: 可在多个机体间切换!

|------|------|
| 饱食度 | 150 |
| 理智值 | 150 |
| 生命值 | 150 |

特性:
- 吃齿轮永久升级: 生命最高400 / 理智最高300 / 饱食最高200

## 麦斯威尔 (Maxwell) — 暗影法师

### 基本信息
- 原名: 威廉·卡特 (William Carter)
- 称号: "暗影法师" (The Shadow Magician) / 前暗影之王
- 年龄: 中年(具体不详)
- 身份: 温蒂的叔叔、查理的前老板/搭档

### 背景故事 — 从失意魔术师到暗影之王

麦斯威尔的经历是饥荒系列最核心的故事线:

1. 失意的魔术师: 威廉·卡特在现实世界中是一个不成功的魔术师。他用"麦斯威尔"作为艺名，渴望成为伟大的表演者。
2. 发现永恒领域: 在一次表演事故后，他发现了通往永恒领域的入口。
3. 暗影魔典: 威廉获得了暗影魔典(Codex Umbra)，一本蕴含着暗影力量的书。通过它，他获得了难以想象的力量。
4. 成为"国王": 威廉利用暗影魔典统治了永恒领域，成为那里的"国王"。他建造了宏伟的宫殿(冒险模式中的最终场景)。
5. 沦为傀儡: 但权力是假的。暗影生物真正的目的是利用他作为傀儡，通过他引诱更多人类进入永恒领域。
6. 引诱无辜者: 麦斯威尔通过收音机联系现实世界的人，引诱他们进入永恒领域 — 包括威尔逊，甚至包括他自己的侄女温蒂。
7. 被解放: 在冒险模式结尾，玩家(Wilson)找到并解放了他。他从王座上被释放，恢复成一个虚弱的老人。
8. 查理的背叛: 查理 — 他的前助手 — 取代他成为新的暗影女王。现在的麦斯威尔是幸存者中的一员，背负着巨大的罪责。

### 人物分析

麦斯威尔是饥荒中最复杂的角色。他不是纯粹的恶人 — 他是被野心吞噬的悲剧者。他的故事关于:
- 才华与野心的危险
- 权力的代价
- 罪责与救赎
- 知识与不可知的力量

他引诱了自己的侄女温蒂 — 这是他在道德上最大的污点，也是他永远无法原谅自己的事情。

### 游戏内设定

| 属性 | 数值 |
|------|------|
| 饱食度 | 150 |
| 理智值 | 200 |
| 生命值 | 75 (全游戏最低!) |

特性:
- 出生携带暗影魔典 + 暗影剑(68伤害) + 暗影甲(95%减伤)
- 可召唤暗影分身: 分身可帮忙砍树、挖矿、战斗

- 暗影分身耗理智而非生命
- 可阅读薇克波顿的魔法书

## 韦伯 (Webber) — 顽皮的蜘蛛

### 基本信息
- 年龄: 约10岁(小男孩)
- 称号: "顽皮的蜘蛛" (The Indigestible)
- 身份: 半人半蜘蛛

### 背景故事

韦伯是饥荒中最天真和最悲剧的角色之一:

1. 他原本是一个普通的人类小男孩
2. 他的父亲与瓦格斯塔夫曾是同事(科学界)
3. 某种事故或实验让他的人类灵魂被困在蜘蛛的身体里
4. 现在是半人半蜘蛛生物 — 有男孩的心智，蜘蛛的外壳
5. 他渴望被接纳，但因为外貌吓跑了所有人
6. 蜘蛛们理解他，成为他的家人

韦伯的故事探讨了一个哲学命题: 即使外表非人，只要内心善良，是否就足以定义一个人？

### 游戏内设定

| 属性 | 数值 |
|------|------|
| 饱食度 | 175 |
| 理智值 | 100 |
| 生命值 | 175 |

特性:
- 所有蜘蛛对他友好(不主动攻击)
- 吃怪物肉无任何惩罚
- 可以用肉雇佣蜘蛛
- 出生带有蜘蛛巢和蜘蛛丝
- 会长蜘蛛胡子(刮下得蜘蛛丝，用于制作)
- 猪人和兔人会主动攻击他(因为他也是怪物)

## 薇克波顿 (Wickerbottom) — 图书馆员

### 基本信息
- 年龄: 老年
- 称号: "图书馆员" (The Librarian)

### 背景故事

薇克波顿的背景是所有角色中最神秘的之一:

1. 她是一名年迈的图书管理员
2. 与其他被引诱进来的人不同，她似乎是主动追寻禁忌知识进入永恒领域的
3. 她在进入之前就已经了解了关于永恒领域的知识 — 这些知识从哪里来的，无人知晓
4. 她不能睡觉 — 传说是因为她的脑海中充斥着太多不可名状的宇宙知识，无法真正休息
5. 她可以制作魔法书来操纵环境(召唤触手、鸟类、闪电等)

她是科学和魔法相交融的体现 — 知识与力量的边界在她身上模糊了。

### 游戏内设定

| 属性 | 数值 |
|------|------|
| 饱食度 | 150 |
| 理智值 | 250 (全游戏最高!) |
| 生命值 | 150 |

特性:
- 自带一级科技(无需建造科学机器即可解锁基础配方)
- 可制作多种魔法书:
  - 《触手论》: 召唤触手
  - 《鸟类大全》: 召唤鸟类
  - 《实用园艺》: 催熟植物
  - 《睡前故事》: 让周围生物入睡
  - 《世界末日》: 召唤闪电
  - 《月之书》: 召唤月亮
- 不能睡觉(帐篷、草席卷等对她无效)
- 不能吃腐烂食物(她是文明人)
- 每本书使用消耗理智
