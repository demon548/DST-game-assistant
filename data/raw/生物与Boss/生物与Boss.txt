# 饥荒联机版 生物与Boss完全图鉴

## 第一部分: 中立生物

### 猪人 (Pig)
- 生命: 200 | 伤害: 33 | 攻击间隔: 3秒
- 刷新: 猪人房(天然生成)或猪王村
- 行为: 白天外出，黄昏回房。可用任何肉雇佣(右键给肉)
- 雇佣: 给1块肉跟随1天(怪物肉也可以!)
- 疯猪: 连续喂4块怪物肉 → 变成疯猪(攻击一切，掉落2大肉+1猪皮)
- 互动: 给猪人帽子它会戴上(纯装饰)
- 掉落: 大肉×1(75%)或猪皮×1(25%)
- 用途: 帮忙砍树(效率一般)、帮忙战斗、猪皮做足球头盔

### 兔人 (Bunnyman)
- 生命: 200 | 伤害: 40 | 攻击间隔: 2秒
- 刷新: 洞穴兔人村(兔人房)
- 行为: 只在洞穴中出现。可用胡萝卜雇佣。
- 警告: 身上带任何肉类靠近兔人(包括背包里的肉) → 兔人立刻攻击!
- 雇佣: 1根胡萝卜跟随1天
- 掉落: 大肉×1(50%)或兔绒×2(50%)
- 用途: 刷噩梦燃料(兔人自动攻击影怪)，建造兔人工厂

### 牛 (Beefalo)
- 生命: 500(普通)/1000(驯化后) | 伤害: 34
- 刷新: 稀树草原
- 行为: 成群生活。发情期(红屁股)攻击一切靠近者。
- 可驯化: 喂食+骑乘训练。驯化后的牛可骑乘(替代步行手杖)和战斗。
- 剃毛: 用剃刀刮牛毛(牛睡觉时)，得牛毛×3
- 掉落: 大肉×3、牛毛×2、牛角×1(33%概率)
- 用途: 牛毛做帽子/燃料、牛粪施肥、帮打怪(发情期时引怪到牛群)

### 企鹅 (Pengull)
- 生命: 150 | 伤害: 33
- 刷新: 冬季海岸边，成群出现
- 行为: 主动攻击靠近者。跳入水中会留下蛋。
- 蛋: 极好的食物来源(晚上去捡)，但企鹅会攻击
- 掉落: 鸟腿×1(10%)、羽毛×1(10%)

### 格罗姆 (Glommer)
- 生命: 100 | 不攻击
- 刷新: 第11天月圆，格罗姆雕像处
- 跟随: 采摘格罗姆花即可让格罗姆跟随
- 格罗姆粘液: 每2-3天产生，吃下回40理智
- 注意: 格罗姆花在物品栏中→满月时格罗姆留下花消失
- 掉落: 格罗姆粘液×1 + 格罗姆翅膀×1 + 怪物肉×3(杀了格的后果)
- 建议: 不要杀格罗姆! 格罗姆粘液是回理智神器

## 第二部分: 敌对生物

### 蜘蛛 (Spider) — 最常见的怪物
| 类型 | 生命 | 伤害 | 特点 |
|------|------|------|------|
| 普通蜘蛛 | 100 | 20 | 黄昏/夜晚从巢穴外出 |
| 蜘蛛战士 | 200 | 20+跳击 | 巢穴被攻击时出现, 跳击伤害高 |
| 洞穴蜘蛛 | 150 | 20 | 洞穴特有，外壳更硬 |
| 喷吐蜘蛛 | 150 | 20(远程) | 远程攻击 |
| 蜘蛛女王 | 2500 | 80 | 3级巢变女王! 生小蜘蛛, 种1级巢 |

掉落: 怪物肉×1(50%)、蛛网×1(25%)、蜘蛛腺体×1(25%)
蜘蛛女王掉落: 怪物肉×4、蛛网×4、蜘蛛帽×1、蜘蛛腺体×2

打法:
- 白天靠近巢穴引出蜘蛛 → 逐个击杀
- 陷阱捕蛛: 在蜘蛛巢旁边做一排陷阱，黄昏蜘蛛出来自动踩
- 蛛网是重要资源(帐篷、捕虫网、冬帽、高礼帽都需要)

### 猎犬 (Hound) — 定期袭击
- 生命: 150 | 伤害: 30
- 机制: 定期发生猎犬袭击(间隔7-15天)
- 数量: 随天数增加(前期2-3只, 后期10+只)
- 特殊: 火猎犬(死亡后点燃周围)、冰猎犬(死亡后冰冻周围)
- 预警: 角色会警告+屏幕震动+听到嚎叫 → 有几秒准备时间!
- 掉落: 怪物肉×1、犬牙×1(火猎犬还掉灰烬, 冰猎犬掉蓝宝石)
- 应对: 狗牙陷阱阵(犬牙+木头+草)、引到牛群/猪人处、沼泽触手处

### 高鸟 (Tallbird)
- 生命: 400 | 伤害: 50
- 刷新: 岩石地带，守卫巢穴(巢里有高鸟蛋)
- 行为: 偷蛋则追击很远! 不要轻易靠近巢穴
- 打法: 打2走1(攻击间隔长, 容易走位)
- 掉落: 大肉×2(100%)

### 触手 (Tentacle)
- 生命: 500 | 伤害: 30 | 攻击间隔: 2秒
- 刷新: 沼泽地带
- 行为: 无法移动。处于隐身状态(只能看到地面微微冒泡)，靠近后钻出攻击。
- 范围: 攻击范围比看起来大
- 掉落: 怪物肉×1(50%)、触手皮×1(25%)、触手尖刺×1(25%, 51伤害武器!)
- 用法: 引蜘蛛/鱼人去打触手 = 白嫖触手尖刺

### 齿轮怪 (Clockwork) — 洞穴/遗迹
| 类型 | 生命 | 伤害 | 特点 |
|------|------|------|------|
| 机械马 | 300 | 33 | 近战，攻击速度快 |
| 机械主教 | 300 | 25(远程) | 远程电球攻击 |
| 机械犀牛 | 300 | 45 | 冲锋攻击(高伤害!) |

掉落: 齿轮×2(100%)
齿轮用途: 冰箱、灭火器、冰火堆、WX-78升级

### 影怪 (Shadow Creature)
- 生命: 75(爬行者)/100(巨喙) | 伤害: 20(爬行者)/50(巨喙)
- 刷新: 理智低于15%时出现
- 打法: 打影怪回理智! 杀一只+15理智(爬行者)或+30(巨喙)
- 策略: 理智低了→打影怪→理智恢复→影怪消失

### 巨鹿 (Deerclops)
- 生命: 4000 | 伤害: 75(玩家)/150(生物)
- 刷新: 冬季第30天夜晚(默认设置)。听到"奇怪的声音"=巨鹿来了。
- 攻击: 大范围拍击。会主动摧毁建筑物。
- 准备: 足球头盔×2-3 + 木甲×2-3 + 火腿棒 + 波兰水饺×5-10
- 打法:
  - A(走位): 打2走1。巨鹿举拳前摇明显，看到前摇→走开。
  - B(借刀): 引到沼泽(触手打)或森林(大量砍树引出树人打)。
  - C(火药): 20个火药秒杀(让巨鹿踩火药，用火把引爆)。
- 掉落: 鹿角(眼球伞材料)×1 + 大肉×8
- 眼球伞: 鹿角+树枝×15+骨头碎片×4 → 100%防雨+240防暑! 必做!

### 熊獾 (Bearger)
- 生命: 6000 | 伤害: 100(玩家)/200(生物)
- 刷新: 秋季(第二年开始)
- 特点: 会摧毁建筑和树木! 愤怒时地面猛击(AoE)
- 准备: 足球头盔×3 + 木甲×3 + 火腿棒 + 水饺×10+
- 打法:
  - A(走位): 打3走1。注意地面猛击前摇(站起来双拳举高)→立刻跑远!
  - B(借刀): 引到树林让它砍树→引出大量树人帮你打(熊獾砍树效率极高)
  - C(火药): 20个火药直接秒
- 掉落: 厚毛皮(熊皮背心材料)×1 + 大肉×8
- 熊皮背心: 最好的保暖身体装备(240保暖值)，也是回理智装备

### 龙蝇 (Dragonfly) — 全游戏最高血量!
- 生命: 27500 | 伤害: 75(普通)/150(火焰)
- 刷新: 夏季沙漠固定刷新点(有岩浆池标志)
- 攻击模式:
  - 普通拍击 → 火焰拍击(引燃) → 三连拍
  - 愤怒状态飞起 → 全屏火焰攻击!
  - 召唤岩浆虫(小的死亡后产生火焰)
- 准备(不要轻敌!): 足球头盔×5+ + 木甲×5+ + 暗影剑/火腿棒 + 水饺×20+ + 石墙材料(20+石砖!) + 冰杖
- 关键策略: 建石墙分隔战场! 龙蝇愤怒时躲石墙后面。
- 打法:
  - 打3走1 → 愤怒时躲石墙 → 先清掉岩浆虫 → 保持走位
  - 冰杖可暂时让龙蝇冷静下来
- 掉落: 龙鳞(龙鳞火炉=永久光源+取暖!)×1 + 各色宝石×2-4

### 蜂后 (Bee Queen)
- 生命: 22500 | 伤害: 60(普通)/120(尖叫-AoE)
- 刷新: 巨型蜂巢(地图固定位置, 需用锤子锤击激活)
- 攻击: 普通攻击 + 持续召唤大量蜜蜂 + 尖叫(范围减速)
- 准备:
  - 温蒂(阿比盖尔AOE清蜜蜂=最佳!)
  - 或: 提前在蜂后附近建10+兔人房或猪人房(兔人自动打蜜蜂)
  - 大量装备+食物
- 打法: 让帮手清蜜蜂 → 持久战打蜂后本体 → 蜂后血量高但攻击不高
- 掉落:
  - 蜂王冠(头部装备, 回理智光环, 转化蜜蜂为友方)
  - 捆绑包装蓝图(永久保鲜道具! 必拿!)
  - 蜂王浆×6-7

### 蚁狮 (Antlion)
- 生命: 6000 | 伤害: 75(沙刺)
- 刷新: 夏季沙漠固定刷新点
- 核心机制: 夏天不进贡 → 引发地震(破坏基地! 随机摧毁建筑!)
- 进贡: 给石头/玩具/暖石等 → 一段时间内不地震
- 打法: 蚁狮在地下时(看到沙刺)跑开 → 浮出来时打2走1
- 掉落: 沙漠石×1-3 + 各色宝石×2-4

### 远古守护者 (Ancient Guardian)

- 刷新: 洞穴迷宫最深处
- 攻击模式:
  - 冲锋: 直线冲撞, 撞到障碍物后短暂眩晕(输出窗口!)
  - 6000血以下新增: 跳跃攻击+地面虚影触手
- 准备: 矿工帽/灯笼 + 足球头盔×2 + 木甲×2 + 火腿棒 + 水饺×10+
- 打法: 引冲锋 → 站柱子后 → 犀牛撞晕 → 全力输出 → 重复
- 掉落: 远古犀牛角(做犀牛甲/远古科技站!) + 远古钥匙 + 大肉×8 + 宝箱

### 克劳斯 (Klaus)
- 生命: 10000(一阶段5000 + 二阶段5000)
- 刷新: 冬季，需要钥匙(无眼鹿掉落)打开赃物袋
- 一阶段: 克劳斯骑冰鹿(冰霜攻击) → 先杀冰鹿
- 二阶段: 克劳斯骑火鹿(火焰攻击) → 先杀火鹿

### 影织者 (Ancient Fuelweaver) — 最终Boss
- 生命: 16000 | 伤害: 100(普通)/150(暗影)
- 刷新: 洞穴中庭(不与任何地形相连的独立区域)
- 需要: 远古钥匙 + 暗影心房 + 化石骨架(8块碎片)
- 全游戏最复杂的Boss战:
  - 需要同时处理: 影织者本体 + 小暗影虫 + 暗影之手 + 不可见状态
  - 需要天气风向标清除暗影之手
  - 需要噩梦护符(方尖碑需要san值极低才能通过)
- 击败后: 远古区全部重置! 铥矿再生! 所有齿轮怪重新刷新!
- 掉落: 骨甲 + 骨盔 + 暗影香炉(控制远古区影怪)

## 第四部分: 猎犬袭击详细机制

- 袭击间隔: 7-15天(随机)
- 通常发生在: 白天开始或黄昏前
- 预警: 角色台词 + 屏幕震动 + 猎犬嚎叫声(持续约30秒)
- 数量公式: 基础2-4只 + 每70天+2只
- 袭击类型:
  - 普通时期: 全部普通猎犬
  - 夏季/秋季: 可能混入火猎犬(死亡引燃)
  - 冬季/春季: 可能混入冰猎犬(死亡冰冻)
  - 后期: 可能同时出现火犬+冰犬

### 狗牙陷阱阵
- 狗牙+1木头+1草=1个狗牙陷阱
- 放在基地外围(离建筑至少1屏幕)
- 猎犬来 → 引到陷阱阵 → 狗踩陷阱 → 逐个击破
- 狗牙陷阱阵还可以对付青蛙雨
