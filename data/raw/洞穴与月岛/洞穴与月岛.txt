### 二、洞穴地形识别与路线

洞穴地形从中心呈放射状分布:

```
地面入口 → 草地/混合区 → 蘑菇林(红/蓝/绿单色)
                              ↓
                       必定衔接: 荧光果平原(洞穴中心!)
                              ↓
                       月光蘑菇林 → 远古档案区
                              ↓
                       苔藓区 → 猴子区(涂黄泥的柱子=快到远古了!)
                              ↓
                       远古遗迹(铥矿+齿轮怪+完整远古科技站)
                              ↓
                       迷宫(白蜘蛛+远古犀牛Boss)
```

### 关键地形详解

| 地形 | 识别特征 | 资源 | 威胁 |
|------|----------|------|------|
| 荧光果平原 | 大量荧光果树+石笋 | 荧光果(核心资源!) | 蜗牛、蠕虫 |
| 蘑菇林(红) | 大量红蘑菇(白天捡) | 红蘑菇(生吃-20血) | 无 |

| 蘑菇林(绿) | 大量绿蘑菇(黄昏捡) | 绿蘑菇(烤熟+15理智!) | 无 |

| 资源 | 获取方式 | 用途 |

| 噩梦燃料 | 敲雕像/杀影怪 | 魔法物品 |
| 活木 | 杀地精(月光蘑菇林) | 暗影装备/魔法 |

#### 完整远古科技站(遗迹最深处)

必须到最深处才能找到完整的远古科技站(被4个影灯包围):

| 可制作物品 | 所需材料 | 效果 |
|------------|----------|------|
| 铥矿甲 | 铥矿×6+噩梦燃料×4 | 90%减伤，1800耐久 |
| 铥矿棒 | 铥矿×3+活木×1 | 60伤害，150耐久 |
| 铥矿皇冠 | 铥矿×4+噩梦燃料×4 | 90%减伤+力量场护盾,1200耐久 |
| 星唤者法杖 | 4噩梦燃料+2活木+1黄宝石 | 召唤星星(范围伤害+光源) |
| 分解法杖 | 4噩梦燃料+2活木+1绿宝石 | 分解物品(非常重要!) |
| 建造护符 | 2噩梦燃料+1绿宝石+2树枝 | 免费建造+材料减半 |
| 远古斧镐 | 铥矿×2+活木×1 | 多功能工具(用于敲疯猪柱子) |

#### 刷铥矿技巧
1. 用建造护符制作物品(材料减半)
2. 用分解法杖分解成品(100%返还材料)
3. 重复循环 → 材料翻倍!
注意: 分解法杖使用会消耗耐久，宝石不会返还。

#### 梦境循环
| 阶段 | 颜色 | 特点 | 应对 |
|------|------|------|------|
| 平静期 | 偏蓝 | 无影怪 | 安全 |
| 警告期 | 偏灰 | 有吼声 | 准备离开或备战 |
| 暴动期 | 偏红 | 大量影怪!影灯激活 | 准备太妃糖/烤绿蘑菇! |

### 四、远古犀牛(迷宫Boss)攻略

- 生命: 10000 | 地点: 迷宫最深处
- 攻击: 冲锋(100伤害，撞到障碍后眩晕)
- 6000血以下: 新增跳跃攻击+地面虚影触手

**打法**:
1. 站在柱子后面
2. 引犀牛冲锋 → 撞到柱子 → 眩晕!
3. 眩晕期间全力输出
4. 重复引诱 → 撞晕 → 输出
5. 6000血以下注意跳跃攻击(朝一个方向跑可躲避)

**掉落**: 远古犀牛角 + 远古钥匙 + 大肉×8 + 宝箱(随机远古装备)

### 五、兔人(Bunnyman)

- 位置: 荧光果平原附近兔人村
- 特性: 身上带任何肉类(含背包!)→兔人立刻攻击
- 雇佣: 给胡萝卜跟随1天
- 用途: 刷噩梦燃料! 兔人自动攻击影怪，效率极高
- 拆房: 等兔人回房时锤房 → 锤一个杀一个
- 或: 身上不带荤食直接锤

---

### 六、洞穴蠕虫(Depths Worm)

洞穴版猎犬。随时间推移越来越多，类似地面的猎犬袭击。
- 生命: 900 | 伤害: 75 | 移动方式: 地下钻出
- 应对: 站撸+走位，或引到兔人村

### 七、中庭(Atrium) — 最终区域

中庭是不与任何地形直接相连的独立区域:

**进入方式**:
- 方法1(正规): 找到洞穴大触手 → 打掉大触手 → 跳入触手洞 → 到达中庭
- 方法2(逃课): 用瞬移杖瞬移进去(鼹鼠帽看清边界)
- 方法3: 食人花/衣柜卡海(老司机专用)

**中庭要点**:
- 需要噩梦护符(方尖碑需要san值极低才能通过)
- 需要远古钥匙+暗影心房+化石骨架(8块碎片)复活影织者
- 影织者是全游戏最复杂的Boss战

## 第二部分: 月岛探秘

### 一、找到月岛

**方法1(最常用)**: 观察地图的边缘海岸线。找到两条非常平直的海岸线边缘，它们面向的海域大概率有月岛。

**方法2(科技)**: 制作星象探测仪探测(需要月岩+铥矿)

**前往月岛**: 建造船(4木板+3绳子) → 出海 → 需要锚(固定船)和船帆(移动)

---

### 二、月岛特色

- 彩色树木(颜色随季节变化): 春夏绿色、秋红色、冬白色
- 理智改为"启示"(Enlightenment)系统: 理智越低，启示越高
- 高启示时: 可建造特殊月亮科技物品
- 温泉: 提供温暖和恢复。投入沐浴球(月岛科技制作)→月圆时温泉结矿→敲掉有几率出宝石
- 玻璃碎片: 制作玻璃刀/玻璃斧的原材料

---

### 三、月石获取

| 方法 | 说明 | 效率 |
|------|------|------|
| 陨石区挖掘 | 等待陨石坠落→挖掘陨石坑 | 低(随机) |
| 猪人石化法 | 用月之法杖将猪石化→杀掉 | 高(每头2-3月石!) |
| 月岛开采 | 月岛天然矿脉 | 中 |

### 四、天体线完整流程

```
1. 远古区 → 拆唤星法杖 → 获得星象探测仪图纸
2. 月圆 + 月台 → 彩虹宝石 → 档案馆解密
3. 主大陆 → 探测并搬运圣殿部件到月岛:
   - 天体圣殿象征(1个)
   - 天体圣殿戎卫(1个)
   - 天体祭坛底座(1个)
   - 天体祭坛宝球(1个)
   - 天体祭坛雕像(1个)
4. 月岛 → 敲三个祭坛碎片 → 拼装圣殿+祭坛
5. 奶奶岛(寄居蟹隐士):
   - 海上瓶中信 → 获取奶奶岛位置
   - 做任务提升好感度: 修缮房屋/种植/清食人花/钓鱼+给食物
   - 每次好感+1, 累计需要10点
   - 好感满10 → 老奶奶赠送珍珠
6. 给帝王蟹镶嵌珍珠+七彩宝石 → 击败 → 获得天体贡品
7. 回月岛 → 将所有部件插入裂隙 → 最后插入天体贡品
8. 触发天体风暴 → 完成3次风暴任务
9. 召唤天体英雄(三阶段Boss)
```

### 五、帝王蟹(Crab King)

- 位置: 海域中随机分布
- 机制: 必须在帝王蟹上镶嵌珍珠+七彩宝石，击败后才能获得天体贡品
- 如果只是普通镶嵌(无珍珠) → 击败后不会有天体贡品

**逃课打法**:
- 杀人蜂法: 在帝王蟹附近放大量杀人蜂
- 冰杖冰面法: 用冰杖造冰面+1珍珠+8红宝石速杀

**2024年Bug**: 击败后天体贡品可能被传到绚丽之门(出生点)，找不到去出生点看看。

### 六、天体英雄 (三阶段)

| 阶段 | 攻击方式 | 策略 |
|------|----------|------|
| 第一阶段 | 近战攻击 + 召唤月灵 | 标准走位 |
| 第二阶段 | 范围AoE + 玻璃尖刺 | 保持距离，躲避AoE |
| 第三阶段 | 全屏激光 + 高速移动 | 最难! 注意节奏 |

击败后: 获得启迪王冠等顶级装备

### 七、玻璃科技

- 玻璃碎片: 月岛开采或挖掘获得
- 可制作:
  - 玻璃刀: 68伤害/100耐久(高伤害武器!)
  - 玻璃斧: 高效砍树工具
  - 月亮科技物品: 需要高启示值
