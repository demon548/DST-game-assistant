## 三、黄金配比: 自给自足零施肥种植!

### 原理
不同作物消耗和产出不同肥料类型。巧妙搭配 → 作物互哺 → 无需施肥!

### 配比表

| 季节 | 最佳配比 | 说明 |
|------|----------|------|
| 🌸春季 | 土豆:番茄=1:1 | 土豆耗红肥产蓝黄 ↔ 番茄耗蓝黄产红 = 完美闭环! |
| 🌸春季 | 番茄:火龙果=2:1 | 高产高价值 |
| ☀️夏季 | 番茄:火龙果=2:1 | 夏天火龙果主力 |
| ☀️夏季 | 西瓜:洋葱=2:1 | 夏天降温作物 |
| 🍂秋季 | 土豆:番茄=1:1 | 经典永不过时 |
| 🍂秋季 | 洋葱:大蒜:辣椒=1:1:1 | 沃利专属，三高价值作物互哺 |
| ❄️冬季 | 南瓜:大蒜:土豆=1:1:2 | 冬季最稳三角 |
| ❄️冬季 | 芦笋:土豆=1:1 | 芦笋冷汤(夏天备) |

### 记忆口诀
```
水果(火龙果/石榴/西瓜) + 调料(洋葱/大蒜/辣椒) = 高耗4肥
番茄和西瓜是例外 — 它们是肥料供应者!

催长剂(蓝): 胡萝卜、南瓜、洋葱、石榴 ← 汤类蔬菜
堆肥(黄): 玉米、芦笋、大蒜、榴莲 ← 粒状外观
粪肥(红): 土豆、茄子、火龙果、辣椒 ← 烤了能整个吃
```

## 四、巨大作物培养 — 七大条件

要让作物长成巨大形态(收获巨大作物)，必须满足所有条件:

| # | 条件 | 具体要求 | 不满足后果 |
|---|------|----------|-----------|
| 1 | 应季种植 | 在作物适应季节种植 | 每阶段压力+1 |
| 2 | 充足水分 | 每阶段水分不低于10%时间 | 每阶段压力+1 |
| 3 | 充足营养 | 每阶段土壤提供足够对应肥料 | 每阶段压力+1 |
| 4 | 无杂物 | 半径1.5地皮内无杂草/腐烂物/杂物 | 每阶段压力+1 |
| 5 | 形成家族 | 半径1地皮内≥4株同种作物 | 每阶段压力+1 |
| 6 | 不拥挤 | 每块地≤10株作物 | 每阶段压力+1 |
| 7 | 对话/幸福 | 每阶段手动对话或用乐器/友好果蝇 | 每阶段压力+1 |

### 压力值结算
| 总压力 | 结果 | 收获 |
|--------|------|------|
| 0-1 | 🌟巨大作物! | 敲碎→2果实3种子 或 3果实2种子 |
| 2-6 | 普通 | 1果实2种子 |
| 7-11 | 普通 | 1果实1种子 |
| ≥12 | 普通 | 1果实0种子 |

### 对话/幸福度方法
- 手动对每株作物按右键对话(费时间!)
- 演奏乐器: 牛角、独奏乐器、排箫、贝壳钟(AoE对话!)
- ⭐友好果蝇(打败果蝇王获得): 自动帮作物对话! 强烈推荐!

### 农产品秤
- 把巨大作物放上去 → 回满新鲜度 → 永鲜保存!
- 敲碎获得满新鲜度的果实和种子
