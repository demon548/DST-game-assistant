# 饥荒联机版 四季生存 + 新手开荒完全攻略

## 第一部分: 新手开荒 (第一年秋季)

### 前3天: 探图 + 收集

探图是新人最重要的技能。前3天应该什么也不建，只为探图。

**探图技巧**:
- 沿地图边缘走 或 沿卵石路走效率最高
- 卵石路尽头大概率是猪王村!
- 探图目的: 找到建家选址所需的全部信息
- 顺便捡基础资源: 草、树枝、燧石、木头、石头、金子

**前3天必须做的事**:
1. 造斧头砍树(至少40木头)
2. 造镐子挖矿(至少20石头、5燧石)
3. 尽快找到5个金子 → 造科学机器(一本)
4. 一本优先解锁顺序: 背包 → 绳子 → 长矛 → 木甲
5. 炼金引擎(二本)做好先打包带身上，不急放下

**夜间处理**:
- 天黑前做火把
- 营地火堆过夜
- 夜晚可做的事: 整理背包、预做木板/石砖、烤浆果

---

### 建家选址 — 最重要的决策

#### 推荐位置排名

| 排名 | 位置 | 优势 | 注意事项 |
|------|------|------|----------|
| 1(最佳) | 猪王村周边桦树林与草原交界 | 猪王无限换金! 猪人帮打狗! 浆果丛/树枝/草三类资源齐全 | 确认无高脚鸟巢穴，蜘蛛巢不超过2个 |
| 2 | 牛群旁边(距离1屏幕) | 牛毛做帽子/燃料，牛粪施肥，牛帮打怪，缺食物可杀牛 | 红屁股发情期会攻击靠近者 |
| 3 | 绿洲(蚁狮沙漠) | 夏天不自燃! 四季有仙人掌 | 夏天有沙尘暴 |
| 4 | 月台旁靠海 | 后期永亮光源 | 需要科技基础才能利用 |

#### 避坑黑名单
- ❌ 沼泽边缘 — 触手+鱼人无限骚扰
- ❌ 牛群发情路径上 — 春天被牛追
- ❌ 巨鹿/鹿角鹅巢穴100格内 — Boss拆家
- ❌ 洞穴入口正上方 — 蝙蝠群骚扰
- ❌ 陨石区地表 — 陨石砸基地
- ❌ 陨石坑/马赛克地形 — 不可预测的陨石

### 基地建设优先级

```
第一梯队(第5-10天):
  石火坑 → 科学机器/炼金引擎 → 烹饪锅×3-4 → 冰箱×2

第二梯队(第10-15天):
  避雷针 → 晾肉架×8-10 → 箱子×5-8 → 帐篷

第三梯队(第15-20天, 入冬前):
  暖石×2 → 冬帽/牛毛帽 → 食物储备(至少20天的量!)

第二年追加(春季后):
  灭火器×2 → 鸟笼 → 蜂箱 → 狗牙陷阱阵
```

**必建清单详解**:

| 设施 | 所需材料 | 建设时机 | 说明 |
|------|----------|----------|------|
| 石火坑 | 12石头+3木头 | 第1天 | 永久火源, 可添加燃料 |
| 烹饪锅×3-4 | 3石砖+6木炭+6树枝/个 | 第5-10天 | 做饭吃, 越多做越快 |
| 冰箱×2 | 2金+1齿轮+1木板/个 | 第7-10天 | 齿轮打齿轮怪获得 |
| 避雷针 | 4金+3石砖 | 第15天前 | 春天前必须有! |
| 晾肉架×10 | 3树枝+3绳子+2木炭/个 | 第10-15天 | 肉干长保质+回理智 |
| 鸟笼 | 2纸+6金+2种子 | 第15-20天 | 芦苇在沼泽采, 造纸 |
| 灭火器×2 | 2电子元件+15冰+2齿轮/个 | 第55天前 | 夏天防止基地自燃! |
| 帐篷 | 6蛛网+4树枝+3绳子 | 有蛛网时 | 睡觉回血回理智 |

## 第二部分: 四季生存

### 🍂 秋季 (Autumn) — 起始季节, 持续20天

**特点**: 温度适中, 无特殊威胁。偶有猎犬袭击。熊獾可能秋季末出现。

**秋季核心任务**:
- 建好完整的基地(见上面的优先级表)
- 移植资源: 树枝、草、浆果丛(移植后必须施肥!)
- 打蜘蛛获取怪物肉 + 蜘蛛丝(做帐篷/捕虫网)
- 第11天月圆: 去格罗姆雕像领格罗姆(格罗姆粘液=回理智)
- 收集齿轮: 打机械马或挖坟获取
- 找到海象牙: 冬季打海象掉落(做步行手杖)

**秋季准备入冬清单**:
- 暖石×2(轮换使用)
- 冬帽 或 牛毛帽
- 食物储备(冬天的浆果丛不结果!)
- 木材储备(冬天篝火消耗大)
- 剃刀: 冬天晚上去刮牛毛

---

### ❄️ 冬季 (Winter) — 持续15天

**核心威胁**:
1. 冻伤: 体温<0℃持续扣血
2. 巨鹿(Deerclops): 第30天夜晚刷新, 生命4000, 伤害75
3. 企鹅(Pengull): 海岸边成群出现, 靠近会攻击
4. 食物生产停滞: 浆果丛/农田冬天不生长

**保暖系统**:
- 基础保暖: 暖石(火边加热到橙色=最高温度)
- 衣物保暖值: 冬帽(120) / 牛毛帽(240) / 熊皮背心(240)
- 冰火堆: 使用噩梦燃料+木头制作，可随时放置
- 火堆旁站一会暖石就热了，然后跑出去活动

**巨鹿预警与应对**:
- 第30天夜晚，角色会提示"听到了奇怪的声音"
- 听到后立刻离开基地! 至少跑2个屏幕远
- 巨鹿会出现在你身边，不要让它靠近基地
- 打法: 打2走1, 或引到沼泽/森林
- 掉落: 鹿角(眼球伞!) + 大肉×8

**冬季食物策略**:
- 怪物肉+冰块=肉丸(冬天的冰可以替代浆果! 冰在冬天满地都是)
- 晾肉架提前做好的肉干
- 去打海象(海象牙=步行手杖, 大肉)
- 企鹅蛋: 冬天晚上去海边捡企鹅下的蛋

---

### 🌧️ 春季 (Spring) — 持续20天

**核心威胁**:
1. 持续下雨: 影响理智和体温
2. 青蛙雨(Frog Rain): 大量青蛙从天而降!
3. 蜜蜂狂暴: 所有蜜蜂变为攻击状态
4. 雷击: 可能引燃基地
5. 鹿鹅(Moose/Goose): 春季刷新

**防雨系统**:
- 100%防雨=雨伞(50%手部)+猪皮帽/橄榄球头盔(50%头部)
- 或雨衣(100%身体, 释放手部)
- 湿度>50时工具可能脱手
- 潮湿食物烹饪效率降低

**青蛙雨应对**:
- 听到青蛙叫声立刻离开基地核心区!
- 青蛙会从天而降覆盖大片区域
- 引青蛙去牛群/沼泽/猪人村 — 让中立生物帮你清理
- 陷阱阵: 在基地外围放一排陷阱(青蛙踩触发)

**避雷针**:
- 覆盖范围: 约2屏幕
- 如果基地大，建2个避雷针分布在两侧
- 被雷击的避雷针会发光几秒

---

### ☀️ 夏季 (Summer) — 持续15天

**核心威胁**:
1. 过热中暑: 体温>70℃持续扣血
2. 自燃(Smoldering): 玩家周围可燃物会自燃! 这是最危险的!
3. 枯萎: 植物停止生长
4. 蚁狮(Antlion): 夏季沙漠刷新
5. 龙蝇(Dragonfly): 夏季沙漠, 27500血

**防暑系统**:
- 冰火堆: 站在旁边降温, 暖石在冰火堆旁变冷
- 眼球伞: 100%防雨+240防暑 — 性价比最高的装备
- 西瓜帽/冰帽: 头部防暑
- 夏日背心: 身体防暑(延迟过热时间)

**灭火器(Snowball Emitter)**:
- 夏天最关键的防御建筑!
- 有效半径: 12格
- 燃料消耗: 冰块和硝石
- 必须覆盖所有木制建筑和可燃物
- 建议建2个覆盖基地
- 绿洲建家可以省灭火器(沙漠不自燃)

**夏天生存策略**:
1. 基地中心放冰火堆，常备暖石冷却
2. 灭火器×2覆盖基地所有可燃物
3. 蚁狮不进贡会引发地震 — 定期送石头/玩具/暖石
4. 或直接下洞穴避暑 — 洞穴温度恒定无季节影响
5. 眼球伞+夏日背心=双重防暑

## 第三部分: 三维管理与恢复

### 饱食度
- 恢复: 肉丸(1肉+3填充,+62.5)、烤浆果(+12.5)、蝴蝶翅膀(+9.4)
- 0饱食: 每秒扣1.25血
- 吃食物时注意新鲜度(绿色=全效, 黄色=2/3, 红色=1/3)

### 生命值
- 恢复: 波兰水饺(+40)、火龙果派(+40)、蝴蝶翅膀(+8)、治疗药膏(+20)
- 帐篷: 满饱食下睡觉, 回大量血和理智(消耗大量饱食)
- 0生命: 死亡变成鬼魂

### 理智值
- 恢复: 烤绿蘑菇(+15)、烤蓝蘑菇(+10)、摘花(+5/朵)、肉干(+15)、蜂王冠
- 降低: 天黑(-5/分)、怪物光环、潮湿、吃腐烂食物、暗影剑装备(-20/分)
- 低于15%: 出现影怪攻击!
- 影怪应对: 打影怪回理智! 杀一只暗影怪+15理智

## 第四部分: 复活机制

| 方式 | 条件 | 惩罚 |
|------|------|------|
| 试金石(Touch Stone) | 地图找到并激活(猪人头+木板) | 无惩罚(一次性) |
| 肉像(Meat Effigy) | 建造: 4木板+3胡子+40生命 | 永久-30最大生命(可用强心针恢复) |
| 无尽模式传送门 | 鬼魂状态进入出生点传送门 | 物品掉落 |
| 生命护符(Life Giving Amulet) | 佩戴自动复活 或 使用救活鬼魂 | 消耗品(使用后消失) |
| 告密的心(TellTale Heart) | 任何玩家制作(3草+1蜘蛛腺体+40血) | 给鬼魂队友复活, 无其他惩罚 |
